SUNRAN ESTATE WEBSITE — START HERE

1. Extract the sunran-estate folder.
2. Open the folder in VS Code (or another code editor).
3. Open index.html in a browser. For best development experience, use VS Code Live Server.
4. The site contains:
   - index.html (homepage)
   - properties.html (search/filter listings)
   - property-details.html (dynamic property details)
   - about.html
   - contact.html
   - favourites.html
   - login.html
   - signup.html
   - css/style.css
   - js/data.js, main.js, properties.js, details.js, favourites.js, contact.js

IMPORTANT BEFORE SELLING:
- All property data, names, prices, locations, phone numbers, testimonials and company details are sample/demo content.
- Replace sample data in js/data.js with verified company listings.
- Replace +2348000000000, hello@sunranestate.com and the office address with the client's real contact details.
- The floating WhatsApp shortcut and property/enquiry WhatsApp actions use +2349057170103.
- Replace image URLs in js/data.js and CSS with the client's licensed property photos.
- The contact form currently prepares an enquiry for WhatsApp; it does not securely store submissions.
- Favourites use LocalStorage on the visitor's device.
- login.html is a front-end demonstration only. It does not authenticate users or store/send login details; connect it to a secure authentication backend before enabling real accounts.
- signup.html is a front-end demonstration only. It does not create accounts or store/send registration details; connect it to a secure authentication backend before enabling registrations.
- This is a frontend demonstration. For a production client website, add a secure backend/database, admin dashboard, server-side form handling, authentication if needed, backups, hosting, domain and security configuration.
- Verify property ownership/title, availability and all listing claims with the client before publishing.
